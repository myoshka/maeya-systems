# Maeya 前屋 — DataViz Concept Library

**Eight interactive design studies**, corresponding to the Hermes Data-Driven Visualisation Research Specification v2.0.

[Open the interactive concept library](./MAEYA_DataViz_Concept_Library.html) (when hosted using GitHub Pages or viewed locally in a browser).

| # | Concept | Evidence basis |
|---|---|---|
| 1 | Harmonic Temporal Flow | Time series uses 43 actual monthly observations. Harmonic layering is only a conceptual demonstration. |
| 2 | Network Topology as Geometric Behaviour | Animated branches are illustrative, because the ZIP does not contain parent-child node records. |
| 3 | Cross-Modal Content Stratification | Reported content-type totals, not time-stamped content-type evolution. Sensory assignments are illustrative. |
| 4 | Dialogue Dynamics as Harmonic Resonance | Illustrative exchange pattern only; no real turn sequence or inter-turn timings supplied. |
| 5 | Complexity Spectrum as Polyhedral Projection | Uses actual counts for the 453 conversation profiles. Shape categories are arbitrary design encodings. |
| 6 | Thoughts & Reasoning as Cross-Modal Provenance | Aggregate reported counts only. No internal-model reasoning or private thoughts inferred. |
| 7 | Temporal Usage as Sonic Seasoning | Actual monthly activity bars; hour/day examples are synthetic and not archive findings. |
| 8 | Continuity Graph as Fractal Growth | Real candidate vocabulary-overlap pairs; links are unverified semantics and deduplicated for display. |

## Data integrity

- **Measured:** 43 monthly records and 453 conversation profiles from Semantic Pass 01.
- **Candidate:** Deduplicated vocabulary-overlap links; no message-level validation.
- **Illustrative:** Node branching, dialogue, content-type time sequences and sensory mappings without the original SQLite rows.
- **Unknown if not provided:** Exact per-message timestamps, verified cognitive-state annotations and provenance of individual reasoning labels.

The HTML is self-contained and makes no external network requests. GitHub's Markdown preview cannot run the HTML JavaScript: open the HTML using GitHub Pages or download it locally.
